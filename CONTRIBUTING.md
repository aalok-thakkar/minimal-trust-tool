# Contributing

Bug reports and pull requests are welcome at
https://github.com/aalok-thakkar/minimal-trust-tool/issues.

## Build and test

```
dune build --profile release
dune test --force
sh test/diff_python.sh
sh test/diff_bounded.sh          # 10 to 15 minutes
python3 test/diff_cpsa.py results/final/cpsa_rows.csv
```

CI runs the build, `dune test` and the differential tests on every push. A change that
alters a verdict, W, H or a call count on any row must explain why in the pull request;
the published data in `results/final/` is not regenerated by contributors.

## Style

- OCaml: standard library and `unix` only. Keep interfaces in `.mli` files with a
  comment for every exported value. Families returned by the library stay
  duplicate-free and in canonical order.
- Tests: random tests take an explicit seed so failures reproduce.
- Python scripts: standard library only.
- The Python reference in `reference/python/` is a fixed comparison point; do not edit
  it. Corrections go in subclasses or wrappers, as in `cpsa/selection/oracle_fixed.py`.
